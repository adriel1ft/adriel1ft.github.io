TutorIA

A research model is useless sitting in a notebook. This one ended up in students’ hands.

Role
Data Scientist
Timeline
Sep 2023 — Sep 2025
Tools
LLMs, Node.js, Docker, APIs

TutorIA is an educational chatbot I built at TRIL Lab. It helps students with complex math problems and with ENEM essay guidance — the kind of support that only works if the model is accurate enough to trust.

The assistant reached about 90% response accuracy. Around it I built a conversational API integrated with AI services, so the research models were not stuck in a demo: students and teachers could actually talk to them.

I also standardized how we developed and shipped this work by containerizing Node.js applications and AI API services with Docker. Same environment from laptop to deploy, and faster CI/CD as a result.
