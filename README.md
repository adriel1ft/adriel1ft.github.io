# adriel1ft.github.io

Personal site for [Adriel Ferreira Trajano](https://adriel1ft.github.io).

Preview locally:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

To add project screenshots, replace the SVGs in `assets/projects/` with images, keeping the same filenames (or update the `src` in `index.html`).
